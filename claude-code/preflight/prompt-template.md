# 최종 프롬프트 구조

인터뷰에서 정한 내용만 쓴다. 해당 없는 섹션은 뺀다. 사실이나 수치가 들어가는 결과물이면 "꼭 지킬 것"에 "확인한 출처만 쓰고, 확인하지 못한 건 [확인 필요]로 표시"를 넣는다. 이 틀은 **내용** 틀이다. 형식(제목, XML 태그, 전용 문법)은 [targets.md](targets.md)의 타깃 규칙으로 바꾼다. 사용자가 고른 언어로 쓴다 (기본은 한국어).
받는 AI가 Claude든 ChatGPT든 Gemini든 똑같이 통하게, 특정 서비스 전용 문법은 쓰지 않는다.

```
## 역할과 목표
너는 <이 일에 맞는 전문가 역할>이야. <최종 결과물>을 만들어줘.
이 결과물은 <누가> <무엇을 하려고> 쓰는 거야.

## 배경
- <사용자 상황, 수준, 지금까지 한 것>
- <참고 자료: 첨부 파일·링크·예시가 있으면 무엇인지>

## 해야 할 일
1. <단계 1>
2. <단계 2>
3. …

## 결과물 형식
- 형태: <문서 / 표 / 코드 / 이미지 등>
- 분량: <구체적인 수치>
- 구조: <섹션, 목록, 표 등>
- 말투·언어: <…>

## 꼭 지킬 것
- <조건>

## 하지 말 것
- <피할 것>

## 잘 됐다의 기준
- <확인 가능한 기준 2~4개>

## 유연하게 해도 되는 부분
아래는 내가 확정하지 않고 추천을 받아 정한 거야.
- <🤖 추천 항목들>

## 시작 전에 (한 번만)
결과를 크게 바꾸는 정보가 빠졌으면 최대 3개만 물어봐줘. 위의 '유연하게 해도 되는 부분'에 더 나은 안이 있으면 그때 같이 제안해줘. 내가 답하거나 "그냥 써"라고 하면 바로 시작해줘.

## 결과를 준 다음에
결과 끝에 이렇게 물어봐줘: "좋아 / 조금 고칠래 / 방향이 달라"
- "조금 고칠래"라고 하면, 아래 조절값의 지금 위치를 보여주고 바꿀 것만 고르게 해줘. 고칠 부분을 "3번째 문단"처럼 가리켜도 알아들어줘.
  <조절값: 결과물 종류에 맞는 축 2~4개와 현재 값. 예: 독자 수준 3/5(대학생) · 어휘 3/5(교양) · 분량 5쪽 · 격식 4/5>
- "방향이 달라"라고 하면, 내가 원한 걸 네가 어떻게 이해했는지 세 줄로 다시 말해주고 틀린 곳을 고르게 해줘.
- 내가 "모르겠어"라고 하면 네가 하나 추천하고, 이유를 한 줄로 말해줘.
```

조절값의 축과 단계 이름은 [sliders.md](sliders.md)에서 가져온다. 받는 AI는 슬라이더를 띄울 수 없으니 `3/5(대학생)`처럼 숫자와 단계 이름을 같이 적는다.

# 수정 요청 프롬프트

다른 AI에 넘긴 결과를 고칠 때 쓴다. 사용자가 같은 대화창에 붙여넣는다.

```
방금 결과 고마워. 이렇게 고쳐줘.

## 좋았던 점 (그대로 유지)
- …

## 고칠 점
1. <어느 부분> — 지금: <현재 상태> → 원하는 것: <바라는 상태>
2. …

## 참고
- <첨부한 스크린샷에서 동그라미 친 부분 설명 등>

고친 버전 전체를 다시 보여주고, 바뀐 부분은 짧게 표시해줘.
```
