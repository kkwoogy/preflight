# 도구 고르기 — 에이전트·플러그인·커넥터

기억에 의존하지 않는다. 지금 이 환경에서 실제로 쓸 수 있는 걸 확인해서 고른다. 서비스 기능은 자주 바뀐다.

## 1. 지금 가진 것부터

- 이미 켜진 스킬, 플러그인, 연결된 커넥터를 먼저 확인한다 (세션에 표시된 목록 등).
- 맞는 게 있으면 그걸 쓴다. 새로 설치하는 건 마지막 수단이다.

## 2. 없으면 찾는다 (그 도구가 있는 환경에서만)

- **플러그인**: 카탈로그를 검색하고(`SearchPlugins`), 맞는 게 있으면 설치 카드를 보여준다(`SuggestPluginInstall`).
- **스킬**: `SearchSkills`, `SuggestSkills`로 찾는다.
- **커넥터**: MCP 레지스트리(`search_mcp_registry`, `suggest_connectors`)에서 찾는다. Gmail, Notion, Drive 같은 건 대부분 로그인 한 번이면 연결된다.
- **문서·슬라이드·디자인 결과물**: 아티팩트 유형을 확인한다(`Artifact`의 quickstart).

이름이 다르거나 없는 도구는 건너뛴다. 없는 기능을 지어내지 않는다.

## 3. 에이전트 쓰기

- 서로 독립적인 일(여러 주제 조사, 여러 파일 분석)은 서브에이전트로 동시에 돌린다.
- 넓은 범위의 파일 탐색은 탐색 전용 에이전트, 설계는 계획 에이전트에 맡긴다.
- 여러 에이전트를 크게 엮는 워크플로는 사용자가 직접 원한다고 말했을 때만 쓴다.

## 4. 실행 위치 고르기

| 이런 일 | 추천 |
|---|---|
| 내 PC 파일 만들기·고치기, 앱 만들기, 여러 도구 조합 | 여기서 바로 |
| 긴 글·문서 | 여기서 바로 또는 Claude |
| 이미지 생성 | 이미지 생성이 되는 서비스 |
| 음악 생성 | 음악 AI (녹음 파일 업로드가 되는지 확인) |
| 최신 정보 조사 | 웹 검색이 되는 곳 (여기서 웹 검색 에이전트, 또는 각 서비스의 리서치 기능) |
| 사용자가 특정 서비스를 원함 | 그대로 따른다 |

## 5. 권한과 설치는 한 번에

- 계획 단계에서 필요한 걸 전부 모은다: 플러그인 설치, 커넥터 연결, 사이트 접근, 작업 폴더 밖 파일, 실행할 명령 종류.
- 사용자가 계획을 승인하면 설치와 연결을 연달아 먼저 끝내고, 그다음에 실행한다.
- 자주 쓰는 안전한 명령 때문에 확인 창이 계속 뜨면 `/fewer-permission-prompts`를 제안한다.
- 결제·비밀번호·약관·계정 만들기는 절대 대신하지 않는다. 어디서 뭘 누르는지까지만 안내한다.
