# 입력 방식 — 타이핑 말고도 받기

질문마다 답하기 가장 쉬운 방식을 고른다. 어떤 방식을 제안하든, 선택지나 글로 답하는 길은 항상 남긴다.

- **다른 입력 방식 제안은 한 번에 최대 1개만 한다.** "어떻게 답할지"까지 고르게 하면 그 자체가 피곤하다. 글보다 확실히 나을 때만 제안한다.
- 방향이 모호할 때 가장 강한 방식은 질문이 아니라 **샘플 2~3개를 나란히 보여주고 고르게 하는 것**이다 (SKILL.md 3단계).

| 이런 걸 물을 때 | 이렇게 받는다 |
|---|---|
| 몇 개 중에서 고르기 | 선택지 (카드, 그림 타일) |
| 정도나 양 (수준, 어휘, 분량, 격식, 예산) | 슬라이더 — 추천값을 미리 맞춰두기 ([sliders.md](sliders.md)) |
| 날짜, 마감 | 날짜 선택 |
| 화면 구성, 구조, 흐름, 공간 배치 | 화이트보드에 대충 그리기, 또는 종이에 그려서 사진 |
| 분위기, 스타일, 색감 | 참고 이미지 붙여넣기, 그림 타일 중 고르기 |
| 지금 화면, 버그, 마음에 안 드는 부분 | 스크린샷 붙여넣기 (+ 동그라미 표시) |
| 이미 가진 자료 | 파일 첨부 |
| 멜로디, 리듬 | 흥얼거림 녹음 (아래 주의 참고) |
| 길고 두서없는 생각 | 음성 입력 |

## 질문 화면 (선택지·슬라이더·날짜·파일)

위젯 표시 도구(`show_widget`)가 있으면 질문 화면(elicitation 폼)을 우선 쓴다. 처음 쓰기 전에 그 도구의 안내(`read_me`의 `elicitation` 모듈)를 먼저 읽는다.

- 한 화면에 여러 질문을 담을 수 있다. 카드, 그림 타일, 슬라이더, 날짜, 파일 첨부를 섞어 쓸 수 있다.
- 모든 질문을 똑같은 버튼으로 만들지 말고, 내용에 맞는 모양을 고른다.
- 첫 화면 맨 위에는 "이렇게 이해했어요" 세 줄과 `맞아` / `조금 달라` 선택지를 놓는다. `조금 달라`에 `data-other`를 달아서 고를 때 직접 고칠 칸이 열리게 한다.
- 선택지 질문에는 추천 선택지에 `(추천)`을 붙이고, 마지막에 `잘 모르겠어, 추천해줘`를 넣는다. 슬라이더는 추천값에 미리 맞춰둔다 (안 건드리면 추천값).
- 사용자가 답하면, 답이 다음 메시지에 한 줄로 모여서 돌아온다.

위젯 도구가 없으면 `AskUserQuestion`을 쓴다. 한 번에 최대 4문항, 문항당 선택지 2~4개이고, 마지막 선택지는 `잘 모르겠어, 추천해줘`로 한다.

## 화이트보드

앱 안 브라우저 도구가 있을 때:

1. Excalidraw(`https://excalidraw.com`, 무료, 로그인 없음)를 연다.
2. 이렇게 안내한다: "여기에 대충 그려주세요. 네모, 화살표, 글씨면 충분해요. 다 그리면 '다 그렸어'라고 해주세요."
3. 다 그렸다고 하면 두 가지 방법으로 읽는다:
   - **스크린샷**: 전체 모양을 본다.
   - **페이지 저장소의 `excalidraw` 항목** (`localStorage.getItem('excalidraw')`): 도형 종류, 글씨, 화살표 연결을 정확히 읽는다. 읽기만 하고 고치지 않는다.
4. 읽은 걸 말로 요약해서 확인받는다: "이렇게 이해했어요: 왼쪽에 메뉴, 가운데 지도, 아래에 목록… 맞아요?"

**아이패드·태블릿으로 그리기** (펜으로 그리는 게 편할 때):

1. 앱 안 브라우저의 Excalidraw에서 **실시간 협업 → 세션 시작**을 누른다. 종단간 암호화되고 로그인은 필요 없다. 세션을 시작하기 전에 사용자에게 먼저 묻는다.
2. 생긴 링크를 사용자에게 준다. 사용자가 아이패드에서 그 링크를 열고 펜슬로 그린다.
3. 그린 내용은 PC 쪽 브라우저에 실시간으로 반영된다. 다 그렸다고 하면 위와 같이 스크린샷으로 읽는다.
4. 끝나면 세션을 종료한다.

브라우저 도구가 없으면, 종이나 태블릿에 그린 걸 사진이나 스크린샷으로 붙여넣어 달라고 한다.

## 사진·스크린샷·참고 이미지

- 채팅에 바로 붙여넣으면 된다고 안내한다. 화면 캡처는 Win+Shift+S, 붙여넣기는 Ctrl+V.
- 받으면 무엇을 이해했는지 한두 줄로 확인받는다.

## 소리 (흥얼거림)

Claude는 소리를 직접 들을 수 없다. 이걸 숨기지 말고 솔직하게 말한다. 대신 이렇게 한다:

- **녹음 파일은 음악 AI로**: 폰 녹음 앱으로 흥얼거려서 저장하게 하고, 녹음 파일을 받아주는 음악 AI에 올리는 걸 준비물 체크리스트에 넣는다. 서비스 이름이나 기능은 실제로 확인한 것만 말한다.
- **분위기는 선택지로**: 빠르기(슬라이더), 느낌(카드), 비슷한 노래 제목으로 받는다.

## 음성 입력

긴 설명이 필요하면 "말로 해도 돼요"라고 안내한다. Windows 기본 음성 입력은 Win+H인데, 한국어가 되는지는 설정에서 확인해야 한다. 음성 받아쓰기 앱을 써도 된다.
