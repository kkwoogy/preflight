# 분야별 점검표

**사용자에게 묻는 목록이 아니다. AI가 스스로 채우는 점검표다.** (SKILL.md 1단계)

- 요청에 맞는 분야를 고르고, 아래 항목을 **전부 AI가 추측해서 채운다.** 근거는 요청 내용, 첨부, 맥락, 기억, 상식이다.
- 항목마다 확신(높음/낮음)과 영향(결과가 크게 달라지나)을 판단한다. 확신이 낮고 영향이 큰 항목만 갈림길 질문이 된다.
- 갈림길 질문을 만들 때는 선택지마다 구체적인 예시를 넣는다. 추천 선택지에는 `(추천)`을 붙이고, 마지막 선택지는 `잘 모르겠어, 추천해줘`로 한다.
- 각 분야의 **입력** 줄은 그 분야에서 타이핑보다 나은 입력 방식이다 ([input-modes.md](input-modes.md)).

## 공통 (모든 분야)

- 결과물을 누가 보나? (나만 / 팀·동료 / 고객·불특정 다수 / 평가자: 면접관·교수 등)
- 이걸로 결국 뭘 하려나? (결정하기 / 제출하기 / 공유·게시 / 배우기)
- 어느 정도 완성도가 필요한가? (빠른 초안 / 바로 쓸 수 있는 수준 / 공들인 최종본)
- 마감이나 시간 제약이 있나?
- 참고할 예시나 "이런 느낌" 자료가 있나?
- 어디서 실행하나? (지금 이 대화 / Claude / ChatGPT / Gemini / 전문 서비스)

## 글쓰기 (자기소개서, 블로그, 이메일, 보고서, SNS 등)

- 글의 종류와 실린 곳 (예: 회사 지원서 / 블로그 / 인스타 / 사내 메일)
- 읽는 사람이 가장 궁금해할 것은?
- 꼭 들어가야 할 내용·경험·숫자
- 말투 (격식 / 친근 / 담백 / 열정적)
- 분량 (글자 수, 문단 수, 읽는 데 걸리는 시간)
- 피해야 할 표현이나 내용
- 내 글 원본이 있나? 새로 쓰기인지 다듬기인지
- 제출용 과제나 지원서라면 AI 사용 규정은? (허용 범위에 따라 "초안 + 내 경험 넣을 자리"처럼 결과물의 형태가 달라진다)

**입력**: 말투는 슬라이더(격식 ↔ 친근), 분량은 슬라이더, 원본이나 참고 글은 파일 첨부나 붙여넣기

## 앱·웹·코딩

- 누가 어떤 기기로 쓰나? (폰 / PC / 둘 다)
- 핵심 기능 3개 (나머지는 나중에)
- 로그인이 필요한가? 데이터를 저장해야 하나? (기기 안에만 / 서버에)
- 이미 있는 코드나 디자인이 있나?
- 어디에 올릴 건가? (내 PC에서만 / 링크로 공유 / 앱스토어)
- 외부 서비스 연동 (지도, 결제, AI, 로그인 등) — 필요하면 API 키·계정이 준비물에 들어간다
- 완성의 기준 (데모만 되면 / 실제로 남이 써도 되는 수준)

**입력**: 화면 구성은 화이트보드에 그리기, 참고할 앱은 스크린샷, 기존 코드는 폴더 경로

## 설계·구조 (서비스 흐름, 시스템 구조, 공간·방 배치 등)

- 무엇을 설계하나? 누가 그 안을 지나가나? (사용자, 데이터, 사람의 동선)
- 핵심 덩어리(화면·방·부품)는 무엇이고, 어떻게 연결되나?
- 꼭 지켜야 할 제약 (크기, 예산, 기존 구조, 법규)
- 지금 가장 고민되는 지점은?
- 결과물 형태 (다이어그램 / 문서 / 3D·도면 / 실제로 만들기)

**입력**: 화이트보드에 덩어리와 화살표 그리기가 기본, 사진이나 도면 첨부

## 조사·리서치

- 무엇을 알아내고 싶나? 최종적으로 내릴 결정은?
- 범위 (국내/해외, 기간, 분야)
- 얼마나 최신이어야 하나? (최신 정보가 필요하면 웹 검색·리서치 기능 필수)
- 믿을 만한 출처 기준 (논문 / 공식 자료 / 뉴스 / 커뮤니티 후기 포함)
- 결과 형태 (요약 / 비교표 / 장단점 / 추천과 이유)
- 출처 링크가 꼭 필요한가? (필요하면 "직접 확인한 출처만, 확인 못 한 건 [확인 필요]"를 프롬프트에 넣는다)

## 디자인·이미지·영상

- 용도와 크기 (인스타 정사각형, 유튜브 썸네일, 포스터, 로고 등)
- 분위기·스타일 (미니멀, 레트로, 귀여운, 고급스러운 등) — 참고 이미지가 있으면 가장 좋음
- 꼭 들어갈 글자, 색, 요소
- 피해야 할 것 (특정 색, 실제 인물·브랜드 등 저작권 문제)
- 몇 가지 시안이 필요한가?

**입력**: 참고 이미지 붙여넣기, 분위기는 그림 타일 중에서 고르기, 배치는 화이트보드

## 음악·소리 (노래, 배경음악, 효과음)

- 용도 (내 노래 / 영상 배경음악 / 앱·게임 효과음)
- 장르와 분위기, 비슷한 노래
- 빠르기, 길이
- 가사가 있나? 있으면 주제와 언어
- 머릿속 멜로디가 있나? 있으면 흥얼거린 녹음
- 상업적으로 쓸 건가? (그러면 라이선스 조건을 확인해야 한다)

**입력**: 흥얼거림 녹음(→ 음악 AI에 업로드), 빠르기는 슬라이더, 분위기는 카드, 비슷한 노래 제목

## 데이터·엑셀·분석

- 데이터가 어디 있나? (파일 / 웹 / 직접 입력) 크기는?
- 알고 싶은 질문은? (추세 / 비교 / 이상한 값 찾기 / 예측)
- 결과 형태 (표 / 차트 / 엑셀 파일 / 한 줄 결론)
- 개인정보가 들어 있나? (있으면 AI에 올리기 전에 지우는 단계를 준비물에 넣는다)

## 기획·아이디어·전략

- 무엇에 대한 기획인가? 지금 어디까지 생각해뒀나?
- 대상 (고객, 사용자, 심사위원 등)
- 제약 (예산, 인원, 기간)
- 원하는 것 (아이디어 많이 / 하나를 깊게 / 비판적 검토 / 실행 계획)
- 비슷한 사례 조사가 필요한가?

## 공부·학습

- 무엇을, 어느 수준까지? (개념만 / 시험 대비 / 실무 적용)
- 지금 내 수준 (완전 처음 / 조금 앎 / 꽤 앎)
- 배우는 방식 선호 (설명 / 예시 / 문제 풀이 / 비유)
- 기간과 하루 공부 시간

## 업무 자동화·반복 작업

- 지금 손으로 어떻게 하고 있나? (순서대로)
- 얼마나 자주? (매일 / 매주 / 가끔)
- 어떤 앱·서비스를 오가나? (메일, 엑셀, 노션, 슬랙 등) — 연결할 커넥터 후보
- 사람이 꼭 확인해야 하는 단계는?
- 실수하면 얼마나 곤란한가? (되돌릴 수 있음 / 없음)

**입력**: 지금 하는 과정을 스크린샷 몇 장으로 보여주기, 순서는 화이트보드에 화살표로
